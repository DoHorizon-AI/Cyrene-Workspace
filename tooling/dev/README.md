# Developer tools

Tools in this directory run only on a developer machine. They never connect to a
VM, publish no public endpoint, and use locally generated fixtures instead of
production credentials.

本目录工具只在开发机运行：不连接 VM，不发布公网入口，使用本地生成的夹具而非生产凭据。
