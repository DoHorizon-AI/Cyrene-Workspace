# Product handoffs / 产品交接

This directory contains operator instructions for frozen, reviewable product
deliveries. Installer binaries and generated release locks travel in the
corresponding delivery archive; they are not committed to this repository.

本目录保存固定产品交付的操作说明。安装包和生成的 release lock 随对应压缩包交付，
不提交到本仓库。先阅读连接说明，再核对版本清单与验收范围。
