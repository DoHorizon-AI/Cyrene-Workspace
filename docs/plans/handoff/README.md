# Product handoffs / 产品交接

This directory contains operator instructions for frozen, reviewable product
deliveries. Installer binaries and generated release locks travel in the
corresponding delivery archive; they are not committed to this repository.

本目录保存固定产品交付的操作说明。安装包和生成的 release lock 随对应压缩包交付，
不提交到本仓库。先阅读连接说明，再核对版本清单与验收范围。

| Handoff / 交付 | Scope / 范围 |
| --- | --- |
| [Navigator V8](cyrene-navigator-v8/README.md) | Windows Alpha client, explicit service connection, frozen versions and recovery evidence / Windows Alpha 客户端、显式服务连接、固定版本和恢复证据 |
| [Navigator final acceptance task](navigator-final-acceptance-task.md) | Executable handoff for remaining acceptance and delivery / 剩余验收与交付的可直接转交提示词 |
