# Contributing to Cyrene-Workspace

Read [AGENTS.md](AGENTS.md), [the development guide](docs/DEVELOPMENT.md), and [the task lifecycle](docs/TASK_LIFECYCLE.md). Use live repository refs and focused PRs into `develop`; promotion to protected `main` and `release` follows the existing branch-flow policy.

Delivery includes normal merge, canonical remote read-back, and a cleanup receipt for temporary worktrees and task branches. Preserve other contributors' work and explicitly record retained tasks.

中文：贡献者和各类 coding agent 应遵守上述开发与交付规范。任务完成后须清理可安全移除的临时工作区和任务分支，并记录尚需保留的工作。不要将提交、推送或关闭 PR 当作完整交付。
